# 实验2复现材料

本目录保存用于复核和复现实验执行过程的本机材料，不属于建议提交的报告正文。

| 子目录 | 内容 | 使用说明 |
| --- | --- | --- |
| `F线自动化脚本/` | F2-F9 PowerShell脚本、TestLink查询与更新辅助PHP脚本、用例映射表和F5结果 | 仅在隔离环境中阅读和复现；执行会调用本机MES或TestLink，不要直接在生产或共享环境运行 |
| `运行日志/` | MES后端运行与错误日志 | 本机调试留档；分享或提交前检查并移除会话、账号等敏感信息 |

最终测试结论和逐项结果以同目录上层的《系统测试报告.docx》为准。凭据不保存在本目录。

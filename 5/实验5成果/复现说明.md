# 接口测试复现说明

1. 按实验2环境指南准备隔离数据库，确认后端服务可用。不要重置已有业务库。
2. 在Postman导入`MES接口测试.postman_collection.json`。设置baseUrl、employeeNo和password为自己的测试环境值；sessionId由登录请求自动取得。集合默认不保存密码。
3. 顺序运行集合。工单详情依赖列表返回的数据；隔离库需有工单和生产任务。不存在工单和失效会话按业务码判断。
4. 也可使用[官方Newman](https://learning.postman.com/docs/collections/using-newman-cli/installing-running-newman)运行。安装Newman6.2.1至工具目录后，用本机临时环境JSON提供变量：`newman run "MES接口测试.postman_collection.json" -e "本机临时环境.json"`。

环境JSON只需包含baseUrl、employeeNo和password。密码仅保存在本机临时文件中；运行后删除该文件。不要把运行中的Postman环境导出、原始Newman JSON或完整登录响应放入仓库，它们可能含密码和会话标识。

本次共享结果为10个请求、20项断言、失败0项。`接口执行明细.csv`保留请求、状态和响应时间，`断言明细.csv`保留每项实际断言结果，`证据/执行汇总.json`仅含脱敏统计。

# Keyboard MES 项目验收与功能冻结说明

更新日期：2026-07-16

## 1. 验收结论

**结论：项目已达到软件类实训项目应具备的基本要求，核心功能可以实现，业务范围从本文件日期起冻结。**

项目不是单纯的增删改查后台。它围绕“工单 - 任务 - 报工 - 质检 - 返修 - 复检 - SN 追溯 - 分析报表”形成了可演示的生产业务闭环，并提供 Web 管理端和微信小程序现场端。代码、数据库脚本、接口文档、演示数据和自动化测试均已具备，适合课程答辩与后续提交。

## 3. 已冻结功能清单

### 后端与数据

- 用户登录、当前用户、退出和 Redis 会话。
- 人员、产品型号、物料、BOM、工艺路线、工单、任务、报工、检验、返修 10 类资源。
- 工单按工艺路线生成任务。
- 任务开工、暂停、完工和报工数量联动。
- 不合格检验自动生成返修单，维修后提交复检。
- 按 SN 聚合完整质量与生产记录。
- 概览和质量报表，支持 `week/month` 与可选 `productModelId`。

### Web 管理台

- 角色化导航、数据表格、分页、表单和业务动作。
- 生产看板、产量趋势、质量构成、型号构成和工位产出。
- 周/月周期切换、全部产品/单一型号切换。
- 产品追溯的业务分组与时间线视图。

### 微信小程序

- 登录、看板、分析、追溯和现场操作。
- 移动报工、质量检验、返修处理。
- 周/月和产品型号维度的分析报表。

## 5. 已知边界

这些项目不阻断课程验收，也不应在提交前继续扩展：

- 小程序正式发布仍需配置 HTTPS 合法域名，并在开发者工具和真机上做最终网络验证。
- 本地运行必须先启动 Redis；Redis 不可用时登录功能不可用。
- 当前权限满足课程项目的岗位级控制，不包含企业级字段权限、组织数据范围和审计平台。
- 当前不接真实 ERP、PLC、检测设备和条码硬件，使用 REST 接口和演示数据模拟业务输入。
- 当前报表面向周/月、全产品/单型号场景，不扩展班次、产线和任意日期钻取。

## 6. 冻结规则

从 2026-07-16 起执行以下规则：

1. 不新增业务表、页面、角色、统计维度或第三方集成。
2. 允许修复阻断启动、核心流程、数据显示或演示的问题。
3. 允许修正文案、样式、测试、部署说明和演示数据。
4. 任何代码修改必须通过后端测试和前端构建，接口变化必须同步文档。
5. 答辩前使用固定演示数据，不临时修改数据库结构或现场录入复杂数据。

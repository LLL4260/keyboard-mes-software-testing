# Keyboard MES 实训项目

面向键盘装配场景的轻量制造执行系统。项目包含 Spring Boot 后端、Vue 3 Web 管理台、微信小程序现场端、MySQL 演示数据和项目文档。

## 已实现范围

- 基础资料：人员岗位、产品型号、物料、BOM、工艺路线。
- 生产执行：生产工单、任务生成、任务状态、报工。
- 质量闭环：质量检验、不合格自动建返修单、维修、返修复检。
- 管理分析：生产概览、周/月产量、全部产品/单一型号分析、不良分布。
- 产品追溯：按产品 SN 聚合报工、质检和返修记录。
- 多端与权限：Web 管理台、小程序轻量现场端、Redis 登录会话、岗位菜单与后端角色校验。

当前业务范围已经冻结。提交前只处理阻断运行、数据错误、文档错误和演示稳定性问题，不再增加业务模块。验收依据见 [项目验收与功能冻结说明](项目验收与功能冻结说明.md)。

## 启动项目

先启动 MySQL 和 Redis。后端默认数据库账号为 `root/password`，可通过 `DB_HOST`、`DB_PORT`、`DB_NAME`、`DB_USERNAME`、`DB_PASSWORD` 和 `REDIS_*` 环境变量覆盖。

```powershell
cd backend
mvn spring-boot:run
```

后端地址：`http://localhost:8088`。

另开终端启动 Web 前端：

```powershell
cd frontend
npm ci
npm run dev
```

Web 地址：`http://localhost:5173`。当前接口客户端直接连接 `http://localhost:8088/api`。

小程序使用微信开发者工具导入 `miniprogram` 目录。开发联调时确认 `miniprogram/utils/api.js` 的 API 地址可从模拟器或真机访问；`project.private.config.json` 属于个人配置，不在交付包中。

### IntelliJ IDEA 运行

1. 将项目 SDK 设置为本机 JDK 17，并以 Maven 项目加载 `backend/pom.xml`。
2. 首次运行前在 `frontend` 目录执行一次 `npm ci`，不要直接执行系统命令 `Vite`。
3. 确认 MySQL 和 Redis 已启动后，依次运行共享配置“Keyboard MES 后端”和“Keyboard MES 前端”。
4. 如果 IDE 仍显示模块未指定 JDK，执行“文件 - 重新加载磁盘中的所有文件”，再重新加载 Maven 项目。

历史 `.idea` 本机配置已清理，IDEA 打开工程后可重新生成；请重新加载 Maven 并选择本机 JDK。代码根目录的 `.run/` 保留共享运行配置。`target/`、`dist/`、`logs/` 和 `node_modules/` 为构建产物、运行日志及依赖。

## 4. 演示业务数据

`reset_rich_mock_data.sql` 会清空当前业务表并重新导入完整演示数据，用于前后端联调、课堂演示、追溯和报表展示。

| 数据 | 用途 |
| --- | --- |
| `KB-ALPHA-87` | 演示产品型号 |
| `V1.0` | 演示 BOM 版本 |
| `R1.0` | 演示工艺路线版本，覆盖装配、检测、包装等工序 |
| 模拟生产工单 | 用于展示工单统计、任务进度、报工、质检、返修和复检 |
| `SN-ALPHA87-0715-001` | 已有报工、质检、返修、复检记录的追溯 SN |

如需接口联调中的具体 ID，直接查询对应列表接口或使用 SQL 查询当前导入数据：

```sql
SELECT id, order_no FROM production_order ORDER BY id;
SELECT id, task_no, order_id FROM production_task ORDER BY id;
SELECT id, rework_no, product_sn FROM rework_order ORDER BY id;
```

业务闭环重复联调顺序：

1. 执行 `reset_rich_mock_data.sql` 重置完整演示数据。
2. 在前端或列表接口中选择一个工单。
3. 调用 `POST /api/productionOrder/{id}/generateTasks` 或在前端点击“生成任务”。
4. 依次执行报工、质检、返修处理、返修复检。
5. 查看工单数据统计、产品追溯和可视化报表。

## 5. 表顺序

插入顺序：

1. `sys_user`
2. `product_model`
3. `material`
4. `product_bom`
5. `process_route`
6. `production_order`
7. `production_task`
8. `work_report`
9. `inspection_record`
10. `rework_order`

删除顺序反向执行。

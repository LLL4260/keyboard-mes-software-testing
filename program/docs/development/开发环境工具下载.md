# 开发环境工具下载

本项目后端使用 Java 17，版本要求见 `program/code/backend/pom.xml` 的 `java.version`。仓库提供 Maven 3.9.9 压缩副本；JDK 17 由成员自行安装，下面列出官方链接和配置方法。

## 仓库内的 Maven

`program/code/toolchain/apache-maven-3.9.9-local.zip` 是从本机 Maven 3.9.9 目录重新打包的 Windows 可用副本，包含软件自带的 `LICENSE`、`NOTICE`。它并非官方 ZIP 文件的逐字节副本；需要核对官方原包时，请使用下表的下载及校验链接。

仓库副本 SHA-256：`F761C7F9AC932E8BF0BEF1D687AB72F9040A2D3484E1D730D82FFE80187CE095`。

从课程仓库根目录运行以下命令，可解压到被 Git 忽略的本地目录：

```powershell
$archive = Join-Path (Get-Location) 'program\code\toolchain\apache-maven-3.9.9-local.zip'
$toolDir = Join-Path (Get-Location) 'program\code\toolchain\.local'
if (-not (Test-Path -LiteralPath (Join-Path $toolDir 'apache-maven-3.9.9'))) {
    Expand-Archive -LiteralPath $archive -DestinationPath $toolDir
}
$env:MAVEN_HOME = Join-Path $toolDir 'apache-maven-3.9.9'
```

## Windows PowerShell 配置

先安装或解压 JDK 17，再在 PowerShell 当前会话设置路径。将示例 JDK 目录替换成实际位置；如已按上文解压 Maven，可沿用 `$env:MAVEN_HOME`。这些命令不会修改系统级环境变量：

```powershell
$env:JAVA_HOME = 'C:\DevTools\jdk-17'
$env:Path = "$env:JAVA_HOME\bin;$env:MAVEN_HOME\bin;$env:Path"

java -version
javac -version
mvn -version
```

`JAVA_HOME` 应指向 JDK 根目录，不要指向 `bin` 或 JRE；`java -version`、`javac -version` 应显示 17，`mvn -version` 应显示 Maven 3.9.9 并使用 JDK 17。在 IntelliJ IDEA 中，也要将项目 SDK 和 Maven Runner 的 JRE 设为 JDK 17。随后在 `program/code/backend` 目录运行 Maven 命令。离线测试 `mvn -o test` 仅在本机 Maven 仓库已缓存项目所需依赖时可用；首次构建通常需要联网下载依赖至用户目录下的 `.m2/repository`。
